[Bay to Breakers](http://en.wikipedia.org/wiki/Bay_to_Breakers) run is a world-famous running event in San Francisco. I had a good time doing my first one on May 18, 2014. Didn't dress up as any funky characters but had my fair share of running into eccentric animals, super heroes, and naked men.
